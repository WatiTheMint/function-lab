# Function Lab — Лабораторія функцій

Інтерактивний навчальний сайт для вивчення функцій та їхніх графіків: побудова графіків,
дослідження властивостей, зміст запису f(x), тренажер «чи є графік функцією»
та вправи «формула ↔ графік».

Чисті HTML, CSS і JavaScript (ES-модулі), без збирання й без залежностей.
Координатна площина малюється на Canvas, формули розбирає власний парсер.

**Сайт:** https://watithemint.github.io/function-lab/

## Запуск локально

Потрібен Node.js 18+ (лише як локальний вебсервер: ES-модулі не завантажуються через `file://`).

```bash
cd function-lab
node server.js
```

Відкрийте <http://localhost:5180>. Порт можна змінити: `node server.js 8080`.

Підійде й будь-який інший статичний сервер, наприклад `python -m http.server 5180`
(на Windows — `py -3 -m http.server 5180`).

Тести математичного ядра (без браузера):

```bash
node tests/run-tests.js
```

## Мова інтерфейсу

Перемикач **УКР / РУС** у шапці сайту. Вибір запам’ятовується в браузері; під час перемикання
зберігається все: побудовані функції, відповіді в тренажері, поставлені точки й масштаб площини.

Усі тексти лежать у словниках `js/i18n/uk.js` і `js/i18n/ru.js` (однакові ключі, підстановки
`{name}`). Щоб додати мову — створіть ще один словник і додайте рядок у `LANGS` у `js/i18n/i18n.js`;
тест `node tests/run-tests.js` перевірить, що ключі й підстановки збігаються.

## Режими

| Режим | Що робить |
|---|---|
| **Графік** | До 8 функцій одночасно: колір, сховати/показати, редагування, видалення зі скасуванням. Аналіз вибраної функції й таблиця значень з точками на графіку. |
| **f(x)** | Вертикальна пряма x = a: тягнути мишею/пальцем, рухати стрілками, вводити x (зокрема `pi/2`). Точка (a; f(a)), проєкції на осі, підстановка «f(3) = 3² + 2 = 11», слід із точок і «пробіг» по осі. |
| **Це функція?** | Випадкові графіки (22 види: параболи, кола, «лежачі» параболи, набори точок, сходинки із зафарбованими й порожніми кінцями…). Відповідь перевіряється критерієм вертикальної прямої, після відповіді — анімована демонстрація й рахунок: правильні, помилки, точність, серія. |
| **Тренування** | «За точками» — поставити точки графіка (таблиця значень, перетягування, прив’язка до сітки, сплайн) і перевірити; «Вибір» — знайти графік формули серед чотирьох; «Формула» — записати формулу за графіком. |

## Як записувати формули

`x^2`, `x²`, `2x + 3`, `3(x+1)`, `1/x`, `(x+1)/(x-1)`, `sqrt(x)`, `√x`, `cbrt(x)`, `|x - 2|`, `abs(x)`,
`sin x`, `sin(2x)`, `sin²x`, `cos`, `tg`, `ctg`, `arcsin`, `arccos`, `arctg`, `e^x`, `exp(x)`, `ln x`,
`lg x`, `log_2(x)`, `pi`, `π`, `e`, `floor(x)`, `sign(x)`. Можна починати з `y =` або `f(x) =`.
Десятковий дріб — `2,5` або `2.5`. Кириличні «х» і «у» сприймаються як латинські.

## Чесний аналіз

Для кожної функції визначаються область визначення, нулі, перетин з Oy, проміжки
зростання й спадання, екстремуми, парність і асимптоти. Кожен висновок має мітку:

- **точно** — знайдено аналітично: многочлени й дробово-раціональні функції (точні корені,
  знаки похідної, ділення многочленів), монотонні композиції (√, ln, eˣ, arctg… від раціональної),
  модуль, тригонометрія від лінійного аргументу (відповіді виду `x = π/2 + πk, k ∈ ℤ`). Ірраціональні
  числа показуються як `√2` або з `≈`;
- **≈ чисельно** — знайдено чисельно на обмеженому відрізку (це оцінка, про що написано поруч);
- **не вдалося** — «Не вдалося визначити автоматично».

Парність доводиться за побудовою формули або спростовується конкретним контрприкладом.

## Доступність

Вкладки й перемикачі мають ролі ARIA та керування стрілками; усі кнопки-іконки підписані;
площину у фокусі можна рухати стрілками й масштабувати `+`/`−`/`0`; пряма x = a в режимі f(x) —
це повзунок (`role="slider"`), яким можна керувати з клавіатури; результати оголошуються через
`aria-live`; враховується `prefers-reduced-motion`. Шрифти завантажуються з Google Fonts,
без мережі використовуються системні.
