# Function Lab — Лаборатория функций

Интерактивный учебный сайт для изучения функций и их графиков: построение графиков,
исследование свойств, смысл записи f(x), тренировка «является ли график функцией»
и упражнения «формула ↔ график».

Чистые HTML, CSS и JavaScript (ES-модули), без сборки и без зависимостей.
Координатная плоскость рисуется на Canvas, формулы разбирает собственный парсер.

**Сайт:** https://watithemint.github.io/function-lab/

## Запуск

Нужен Node.js 18+ (только как локальный веб-сервер: ES-модули не загружаются по `file://`).

```bash
cd function-lab
node server.js
```

Откройте <http://localhost:5180>. Порт можно поменять: `node server.js 8080`.

Подойдёт и любой другой статический сервер, например `python -m http.server 5180`
(на Windows — `py -3 -m http.server 5180`).

Тесты математического ядра (без браузера):

```bash
node tests/run-tests.js
```

## Режимы

| Режим | Что делает |
|---|---|
| **График** | До 8 функций одновременно: цвет, скрыть/показать, правка, удаление с отменой. Анализ выбранной функции и таблица значений с точками на графике. |
| **f(x)** | Вертикальная прямая x = a: тянуть мышью/пальцем, двигать стрелками, вводить x (в том числе `pi/2`). Точка (a; f(a)), проекции на оси, подстановка «f(3) = 3² + 2 = 11», след из точек и «пробег» по оси. |
| **Это функция?** | Случайные графики (22 вида: параболы, окружности, «лежачие» параболы, наборы точек, ступеньки с закрашенными и пустыми концами…). Ответ проверяется критерием вертикальной прямой, после ответа — анимированная демонстрация и счёт: правильные, ошибки, точность, серия. |
| **Тренировка** | «По точкам» — поставить точки графика (таблица значений, перетаскивание, привязка к сетке, сплайн) и проверить; «Выбор» — найти график формулы среди четырёх; «Формула» — записать формулу по графику. |

## Как записывать формулы

`x^2`, `x²`, `2x + 3`, `3(x+1)`, `1/x`, `(x+1)/(x-1)`, `sqrt(x)`, `√x`, `cbrt(x)`, `|x - 2|`, `abs(x)`,
`sin x`, `sin(2x)`, `sin²x`, `cos`, `tg`, `ctg`, `arcsin`, `arccos`, `arctg`, `e^x`, `exp(x)`, `ln x`,
`lg x`, `log_2(x)`, `pi`, `π`, `e`, `floor(x)`, `sign(x)`. Можно начинать с `y =` или `f(x) =`.
Десятичная дробь — `2,5` или `2.5`. Кириллические «х» и «у» понимаются как латинские.

## Честный анализ

Для каждой функции определяются область определения, нули, пересечение с Oy, промежутки
возрастания и убывания, экстремумы, чётность и асимптоты. У каждого вывода есть метка:

- **точно** — найдено аналитически: многочлены и дробно-рациональные функции (точные корни,
  знаки производной, деление многочленов), монотонные композиции (√, ln, eˣ, arctg… от рациональной),
  модуль, тригонометрия от линейного аргумента (ответы вида `x = π/2 + πk, k ∈ ℤ`). Иррациональные
  числа показываются как `√2` или с `≈`;
- **≈ численно** — найдено численно на ограниченном отрезке (это оценка, об этом написано рядом);
- **не удалось** — «Не удалось определить автоматически».

Чётность доказывается по построению формулы или опровергается конкретным контрпримером.

и кнопка-вкладка с `data-mode` в `index.html`.

## Доступность

Вкладки и переключатели — с ролями ARIA и управлением стрелками; у всех кнопок-иконок есть
подписи; плоскость в фокусе двигается стрелками и масштабируется `+`/`−`/`0`; прямая x = a в
режиме f(x) — это ползунок (`role="slider"`), управляемый с клавиатуры; результаты объявляются
через `aria-live`; учитывается `prefers-reduced-motion`. Шрифты подгружаются с Google Fonts,
без сети используются системные.
